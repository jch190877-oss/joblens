方法说明

采用 Saaty 层次分析法：由判断矩阵求最大特征值对应的特征向量，归一化后即为权重。 一致性指标 CI = (λmax − n) / (n − 1)， 一致性比率 CR = CI / RI。当 CR < 0.1 时，视为判断前后自洽、可接受。 若 CR ≥ 0.1，说明存在互相矛盾的判断（例如 A 比 B 重要、B 比 C 重要，却又说 C 比 A 重要），需要回看并调整。

n=5 时 RI = 1.12。两位 HR 分别填写后，用几何平均合并两人的判断矩阵，再求一次权重，可减少个人偏好影响。
